# Sistema de Gestión de Prácticas Profesionales (SGPP)

El Sistema de Gestión de Prácticas Profesionales (SGPP) es una aplicación web diseñada para facilitar la administración y seguimiento de las prácticas profesionales de los estudiantes en instituciones educativas. Este sistema permite a los estudiantes, supervisores y administradores gestionar de manera eficiente las prácticas profesionales, desde la inscripción hasta la evaluación final.
